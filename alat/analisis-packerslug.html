Analisis Packer Test & Slug Test

Analisis permeabilitas batuan/akuifer menggunakan Packer Test (Nilai Lugeon) dan Slug Test (Metode Hvorslev).

Panduan Packer & Slug Test

Packer Test

Konduktivitas Hidrolik:

\[ k = \frac{Q}{2 \pi L h} \ln\left(\frac{L}{r}\right) \]

Nilai Lugeon:

\[ Lu = \frac{10 \times Q}{P \times L} \]

Slug Test (Hvorslev)

Konduktivitas Hidrolik:

\[ k = \frac{r^2 \ln(L_e / R)}{2 L_e t_{37}} \]
