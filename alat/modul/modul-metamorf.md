# MODUL PANDUAN: TATA NAMA BATUAN METAMORF (NOMENKLATUR)
**Referensi Utama:** IUGS Subcommission on the Systematics of Metamorphic Rocks (SCMR) - Smulikowski et al. (2007)

---

## 1. PRINSIP DASAR PENAMAAN
Penamaan batuan metamorf tidak dilakukan sembarangan. IUGS menetapkan hierarki penamaan berdasarkan urutan berikut:

1.  **Nama Dasar (Root Name):** Dentukan berdasarkan tekstur umum (misal: Gneiss, Schist) atau komposisi dominan (misal: Marble, Quartzite).
2.  **Qualifier Struktur:** Menjelaskan struktur khusus (misal: *Augen* Gneiss).
3.  **Qualifier Mineral:** Menjelaskan mineral penyusun penting.

### Rumus Baku Penamaan:
$$\text{[Mineral Minor] + [Mineral Utama] + [Nama Dasar]}$$

> **Aturan Urutan Mineral:** Mineral ditulis dengan urutan **kelimpahan yang meningkat** (dari sedikit ke banyak) mendekati nama dasar batuan.
> *Contoh:* Jika batuan punya 10% Garnet dan 30% Muskovit, namanya: **Garnet Muscovite Schist**.

## 2. LANGKAH 1: MENENTUKAN NAMA DASAR (ROOT NAME)

Gunakan **Diagram Alir** berikut untuk menentukan Root Name.

### A. Apakah Batuan Memiliki Foliasi? (Penjajaran Mineral)

Jika **YA (Terfoliasi)**, tentukan berdasarkan jarak spasi foliasi dan ukuran butir:

| Nama Dasar | Kriteria Tekstur (IUGS) | Ukuran Butir |
| :--- | :--- | :--- |
| **Slate** (Batusabak) | *Slaty Cleavage*. Batuan membelah sangat tipis (<1mm). Tidak ada butiran mineral yang terlihat mata telanjang. | Sangat Halus |
| **Phyllite** (Filit) | Foliasi terlihat bergelombang. Permukaan memiliki kilap sutra (*silky luster/sheen*) akibat mika mikroskopis. | Halus |
| **Schist** (Sekis) | *Schistosity*. Mineral pipih (mika/amphibole) terlihat jelas dengan mata telanjang dan berorientasi sejajar. | Sedang - Kasar |
| **Gneiss** (Gneis) | *Gneissic banding*. Pemisahan (segregasi) mineral gelap dan terang membentuk lapisan belang-belang. | Kasar |

---

### B. Apakah Batuan Tidak Terfoliasi (Granofels)?

Jika **TIDAK (Masif)**, tentukan berdasarkan komposisi mineral dominan (>50%):

| Komposisi Dominan | Nama Dasar Batuan | Uji Konfirmasi |
| :--- | :--- | :--- |
| **Kalsit / Dolomit** | **Marble** (Marmer) | Bereaksi dengan HCl. Lunak (Mohs 3). |
| **Kuarsa** | **Quartzite** (Kuarsit) | Sangat keras (Mohs 7), pecahan memotong butir. Tidak bereaksi HCl. |
| **Hornblende + Plagioklas** | **Amphibolite** | Warna hitam legam/hijau tua. Berat jenis tinggi. (Bisa sedikit terfoliasi). |
| **Mineral Serpentin** | **Serpentinite** | Warna hijau, licin (*greasy*), kilap lilin. Asal dari batuan ultrabasa. |
| **Material Karbon** | **Anthracite** | Hitam, ringan, kilap tinggi. Metamorfisme dari batubara. |
| **Kumpulan Silikat Keras** | **Hornfels** | Butiran sangat halus, sangat keras, pecahan tajam (*conchoidal*), "baked". Terjadi di kontak intrusi. |
| **Campuran Mineral Lain** | **Granofels** | Istilah umum IUGS untuk batuan metamorf masif yang komposisinya tidak spesifik (misal: *K-feldspar-Quartz Granofels*). |

## 3. LANGKAH 2: PENGGUNAAN AWALAN (PREFIX) KHUSUS

Jika tekstur asal batuan induk (*protolith*) masih terlihat jelas atau asal-usulnya diketahui:

### A. Prefix "Meta-"
Digunakan jika batuan mengalami metamorfisme derajat rendah dan ciri batuan asal masih sangat jelas.
* **Metasediment:** Batuan sedimen terubah lemah.
* **Metabasalt:** Basalt terubah lemah (mineralogi berubah tapi tekstur beku masih ada).
* **Metagabbro:** Gabbro terubah lemah.

### B. Prefix "Ortho-" dan "Para-"
Digunakan untuk gneis atau batuan derajat tinggi untuk menunjukkan asal batuan.
* **Orthogneiss:** Gneis yang berasal dari batuan beku (misal: Granit yang terdeformasi).
* **Paragneiss:** Gneis yang berasal dari batuan sedimen (misal: Batupasir kaya lempung yang terdeformasi).

## 4. LANGKAH 3: BATUAN TERDEFORMASI (FAULT ROCKS)
Klasifikasi berdasarkan *Wiseman et al. (1939)* dan *Sibson (1977)* untuk batuan di zona sesar.

| Sifat Material | Matriks Halus (%) | Nama Batuan |
| :--- | :--- | :--- |
| **Brittle** (Pecah-pecah) | < 10% | **Fault Breccia** (Breksi Sesar) |
| *(Menyudut, tanpa foliasi)* | 10 - 50% | **Fault Gouge** (Jika lunak/lempung) |
| | > 50% | **Cataclasite** (Jika keras/tersemen) |
| | | |
| **Ductile** (Plastis) | 10 - 50% | **Protomylonite** |
| *(Tergerus halus, ada foliasi)* | 50 - 90% | **Mylonite** |
| | > 90% | **Ultramylonite** |

## 5. LANGKAH 4: BATUAN KHUSUS (SPECIAL CONTEXT)

### A. Migmatite (Mehnert, 1968)
Batuan campuran metamorf dan beku (lelehan parsial/anateksis).
* **Paleosome:** Bagian batuan metamorf tua (biasanya gneiss gelap).
* **Neosome:** Bagian baru yang terbentuk dari lelehan.
    * *Leucosome:* Bagian terang (granitik/kuarsa-feldspar) hasil lelehan.
    * *Melanosome:* Bagian gelap residu (biotit/amphibole).

### B. Batuan Tekanan Tinggi (High Pressure)
* **Blueschist:** Sekis berwarna biru (mengandung Glaucophane). Indikasi zona subduksi.
* **Eclogite:** Batuan sangat keras, masif, terdiri dari **Omphacite** (Piroksen Hijau) dan **Garnet** (Merah). Tanpa Plagioklas. Indikasi kedalaman mantel/subduksi dalam.

## 6. CONTOH APLIKASI PENAMAAN

Berikut contoh cara merangkai nama batuan di lapangan:

**Kasus 1:**
* **Pengamatan:** Batuan berfoliasi kasar (belang-belang).
* **Root Name:** Gneiss.
* **Mineral:** Terdiri dari Kuarsa, Feldspar, Biotit (banyak), dan ada kristal Garnet (sedikit).
* **Nama IUGS:** **Garnet Biotite Gneiss**.

**Kasus 2:**
* **Pengamatan:** Batuan masif, warna hijau, licin.
* **Root Name:** Serpentinite.
* **Struktur:** Ada gerusan dan foliasi kuat.
* **Nama:** **Sheared Serpentinite** atau **Foliated Serpentinite**.

**Kasus 3:**
* **Pengamatan:** Batuan dasar sekis (Schist), tapi mengandung mineral Kyanite cukup banyak.
* **Nama:** **Kyanite Schist**. (Catatan: Kyanite adalah mineral indeks penting, jadi harus disebut).
