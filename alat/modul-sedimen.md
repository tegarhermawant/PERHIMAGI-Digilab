## 1. ALUR KERJA UMUM (FIELD WORKFLOW)

Sebelum menamai batuan, tentukan kategori utama berdasarkan komponen penyusunnya:

1.  **Silisiklastik (Detritus):** Terdiri dari pecahan batuan (kuarsa, feldspar, lithic) hasil rombakan. -> *Gunakan Klasifikasi Pettijohn/Folk.*
2.  **Karbonat:** Bereaksi dengan HCl, terdiri dari material karbonat (fosil, ooid, peloid). -> *Gunakan Klasifikasi Dunham.*
3.  **Piroklastik:** Material vulkanik hasil letusan. -> *Gunakan Klasifikasi Fisher.*

## 2. BATUAN SEDIMEN SILISIKLASTIK

### A. Skala Ukuran Butir (Wentworth Scale)
Gunakan komparator untuk menentukan ukuran rata-rata (*mean grain size*).

| Nama Butir (Ind) | Istilah (Ing) | Ukuran (mm) | Skala Phi ($\phi$) | Nama Batuan (Litifikasi) |
| :--- | :--- | :--- | :--- | :--- |
| **Brangkal** | Gravel | $> 2$ mm | $<-1$ | Konglomerat / Breksi |
| **Pasir** | Sand | $1/16 - 2$ mm | $-1$ s.d. $4$ | Batupasir (*Sandstone*) |
| **Lanau** | Silt | $1/256 - 1/16$ mm | $4$ s.d. $8$ | Batulanau (*Siltstone*) |
| **Lempung** | Clay | $< 1/256$ mm | $>8$ | Batulempung (*Claystone*) |

### B. Klasifikasi Batuan Kasar (> 2mm)
* **Konglomerat:** Bentuk butiran membundar (*rounded*).
* **Breksi:** Bentuk butiran menyudut (*angular*).
    * *Oligomiktik:* Komposisi klastika seragam (satu jenis batuan).
    * *Polimiktik:* Komposisi klastika beragam.

### C. Klasifikasi Batupasir (Pettijohn, 1975)
Langkah identifikasi:
1.  **Cek Matriks:** Apakah ada butiran halus (<0.03 mm) di sela-sela pasir?
2.  **Cek Komposisi Butir:** Tentukan persentase Kuarsa (Q), Feldspar (F), dan Lithic (L).

#### Langkah 1: Tentukan Tekstur (Arenite vs Wacke)
| Persentase Matriks | Tipe Batuan | Deskripsi |
| :--- | :--- | :--- |
| **0% - 15%** | **Arenite** | "Clean Sandstone", porositas baik, terpilah baik. |
| **15% - 75%** | **Wacke** | "Dirty Sandstone", butiran pasir mengambang di lumpur. |
| **> 75%** | **Mudstone** | Masuk klasifikasi batuan halus. |

#### Langkah 2: Tentukan Nama Spesifik
**Grup Arenite (<15% Matriks):**
* **Quartz Arenite:** $>95\%$ Kuarsa. (Warna terang/putih, keras).
* **Arkose:** $>25\%$ Feldspar. (Warna pink/kemerahan, butiran feldspar menyudut).
* **Lithic Arenite:** $>25\%$ Lithic. (Warna gelap, "salt and pepper").

**Grup Wacke (>15% Matriks):**
* **Quartz Wacke:** Dominan kuarsa + matriks lempung.
* **Feldspathic Wacke:** Kuarsa + Feldspar + matriks.
* **Greywacke (Lithic Wacke):** Kuarsa + Lithic + matriks gelap (sering berasosiasi dengan turbidit).

### D. Klasifikasi Batuan Halus (Mudrock)
Identifikasi fisik sederhana (tanpa sayatan tipis):

| Sifat Fisik | Ukuran Dominan: Lanau (Kasar) | Ukuran Dominan: Lempung (Licin) |
| :--- | :--- | :--- |
| **Memiliki Bidang Belah** (*Fissile*) | Silt-Shale | Clay-Shale (Serpih) |
| **Masif / Tidak Membelah** | Batulanau (*Siltstone*) | Batulempung (*Claystone*) |
| *Campuran Lanau & Lempung* | **Mudstone** (Batulumpur) | |

## 3. BATUAN SEDIMEN KARBONAT (Klasifikasi Dunham, 1962)
**Penting:** Selalu lakukan uji HCl. Nama batuan didasarkan pada tekstur pengendapan (hubungan antar butir).

**Komponen:**
* **Grains:** Alochem (Fosil, Ooid, Pellet, Intraklast).
* **Mud:** Mikrit (Lumpur karbonat, buram).
* **Cement:** Sparit (Kristal kalsit bening).

| Tekstur Pengendapan | Nama Batuan | Ciri Identifikasi Lapangan |
| :--- | :--- | :--- |
| **Mud Supported** | **Mudstone** | $<10\%$ butiran fosil, dominan lumpur kapur. |
| *(Butiran mengambang)* | **Wackestone** | $>10\%$ butiran fosil, tapi masih didukung lumpur. |
| **Grain Supported** | **Packstone** | Butiran saling bersentuhan, tapi sela-selanya terisi lumpur. |
| *(Butiran saling menyangga)* | **Grainstone** | Butiran saling bersentuhan, **tidak ada lumpur**, sela-sela terisi semen bening (sparit). |
| **Bound** | **Boundstone** | Komponen organik tumbuh terikat (Contoh: Terumbu Koral). |
| **Crystalline** | **Crystalline Limestone**| Tekstur asli hilang karena rekristalisasi. |

## 4. DESKRIPSI STRUKTUR SEDIMEN

Catat struktur untuk interpretasi lingkungan pengendapan.

* **Perlapisan (Bedding):** Tebal lapisan $>1$ cm.
* **Laminasi (Lamination):** Tebal lapisan $<1$ cm.
* **Graded Bedding:** Perubahan ukuran butir (menghalus ke atas = *Normal*, mengasar ke atas = *Reverse*).
* **Cross-bedding:** Lapisan miring (indikasi arus purba).
* **Ripple Marks:** Gelombang permukaan (arus air/angin).
* **Bioturbasi:** Bekas jejak/galian organisme.
